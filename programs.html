Compliance-Based Training

Our most-enrolled track, and the quickest route into a stable corporate role for graduates from any stream. You learn to read a policy, apply it to a real case, document the decision so it survives an audit, and escalate the ones that need a second pair of eyes. That is the daily work of compliance, KYC, and trust-and-safety teams, and every one of them is hiring.

  1. Week 1 · How compliance works. Why rules exist, policy versus law, risk-based thinking, and the Indian landscape: RBI, SEBI, the IT Act, the Consumer Protection (E-Commerce) Rules, and the DPDP Act.
  2. Week 2 · Product & marketplace compliance. Restricted and prohibited products, listing and labelling rules, certifications, safety standards, and dangerous goods classification.
  3. Week 3 · KYC, AML & fraud. Customer due diligence, enhanced checks, sanctions and PEP screening, red flags, and how suspicious activity is reported under the PMLA.
  4. Week 4 · Trust & safety. Applying content and conduct policy consistently, counterfeit and IP complaints, review abuse, and when to escalate.
  5. Week 5 · Data privacy. Consent, personal data handling, retention, and breach reporting under the DPDP Act, taught as the practical habits a compliance desk actually needs.
  6. Week 6 · Investigation & documentation. Writing case notes that stand up in an audit, evidence trails, reading an SOP, and root-cause analysis when the same defect keeps coming back.
  7. Week 7 · Tools & data. Excel pivots and lookups, SQL basics for analysts, working a case queue against an SLA, and quality audits.
  8. Week 8 · Capstone. A timed case-queue simulation scored on accuracy and turnaround, plus mock interviews built on real screening questions.

Placed as: Compliance Analyst, Product Compliance Specialist, KYC / AML Analyst, Trust & Safety Associate, Risk Operations Analyst, Quality Auditor.

Eligibility: Any graduate, any stream. No coding. What matters is careful reading and attention to detail, which the aptitude test checks with a short policy-reading exercise.

Commitment: 12–15 hours a week.

Full-Stack Java Development

The backbone track. You'll write production-shaped backend services, wire them to a React front end, and learn to work in a branch-and-review workflow the way a team actually does.

  1. Weeks 1–3 · Java core. Syntax, OOP, collections, exceptions, streams, and unit testing with JUnit.
  2. Weeks 4–5 · Databases. Relational modelling, SQL joins and aggregation, indexing basics, JDBC, and JPA/Hibernate.
  3. Weeks 6–8 · Spring Boot. Dependency injection, REST API design, validation, error handling, security with JWT, and layered architecture.
  4. Weeks 9–11 · Front end. Modern JavaScript, React components and hooks, state management, forms, and consuming your own API.
  5. Weeks 12–13 · Engineering practice. Git branching, code review etiquette, Docker basics, a CI pipeline, and reading logs to debug.
  6. Weeks 14–16 · Capstone. A reviewed, deployed full-stack application plus DSA and system-design interview drills.

Placed as: Software Engineer, Java Developer, Backend Engineer, Application Developer.

Eligibility: Any graduate. Basic programming logic expected; our free two-week bridge module covers it if you're starting cold.

Commitment: 18–22 hours a week including labs.

Data Engineering & Analytics

For people who like structure and want to work close to the data. You'll build pipelines that run on a schedule, survive bad input, and get reviewed like production code.

  1. Weeks 1–3 · SQL in depth. Window functions, CTEs, query plans, and performance tuning on a realistic warehouse.
  2. Weeks 4–5 · Python for data. Pandas, file and API ingestion, scripting hygiene, and testing transformations.
  3. Weeks 6–8 · Warehousing. Dimensional modelling, slowly changing dimensions, incremental loads, and dbt.
  4. Weeks 9–10 · Big data. Spark fundamentals, partitioning, file formats, and cost-aware processing.
  5. Weeks 11–12 · Orchestration. Airflow DAGs, retries and idempotency, data quality checks, and alerting.
  6. Weeks 13–14 · Capstone. An end-to-end pipeline with a dashboard on top, plus case-style interview practice.

Placed as: Data Engineer, Analytics Engineer, BI Developer, Data Analyst.

Eligibility: Any graduate comfortable with logic and numbers. Prior SQL is helpful, not required.

Commitment: 16–20 hours a week.

Cloud & DevOps Engineering

Infrastructure as a discipline. Everything you build here is scripted, version controlled, and torn down again, because that's how the job works.

  1. Weeks 1–2 · Foundations. Linux administration, shell scripting, DNS, TCP/IP, HTTP, and TLS.
  2. Weeks 3–5 · Cloud core. Compute, storage, VPC networking, IAM, managed databases, and cost control.
  3. Weeks 6–7 · Containers. Docker images and layers, registries, Kubernetes deployments, services, and config.
  4. Weeks 8–9 · Automation. Terraform modules and state, plus configuration management patterns.
  5. Weeks 10–11 · Delivery & observability. Pipeline design, artefact promotion, metrics, logs, dashboards, and on-call basics.
  6. Week 12 · Capstone. A fully automated environment stood up from an empty account, documented as a runbook.

Placed as: Cloud Engineer, DevOps Engineer, Site Reliability Associate, Platform Support Engineer.

Eligibility: Any graduate. Suits IT support and networking backgrounds especially well.

Commitment: 15–18 hours a week. Cloud lab credits included.

QA & Test Automation

The shortest route into a product team for most career switchers, and a genuine engineering discipline once you're in.

  1. Weeks 1–2 · Foundations. Test design, equivalence partitioning, defect lifecycle, and writing a bug report that gets fixed.
  2. Week 3 · Programming for testers. Enough Java or Python to automate confidently.
  3. Weeks 4–5 · Web automation. Selenium, locators, waits, the page object pattern, and TestNG.
  4. Weeks 6–7 · API & modern tooling. REST testing with Postman and RestAssured, plus Playwright.
  5. Week 8 · Test in the pipeline. Running suites in CI, reporting, flakiness, and test data management.
  6. Weeks 9–10 · Capstone. A regression suite for a real application with a written test strategy.

Placed as: QA Engineer, Automation Test Engineer, SDET, Quality Analyst.

Eligibility: Any graduate. No coding background needed.

Commitment: 12–15 hours a week.

Business Analysis & Product Ops

Built for people with domain experience who want to move into a product or delivery team. Your existing industry knowledge is an asset here, not something to explain away.

  1. Weeks 1–2 · The BA role. Stakeholder mapping, elicitation techniques, and scoping a problem before proposing a solution.
  2. Weeks 3–4 · Documentation. User stories, acceptance criteria, BRD and FRD structure, and process modelling with BPMN.
  3. Week 5 · Data literacy. SQL for analysts, spreadsheet modelling, and reading a dashboard critically.
  4. Weeks 6–7 · Agile delivery. Backlog refinement, estimation, sprint ceremonies, and working with Jira boards.
  5. Week 8 · Product thinking. Prioritisation frameworks, wireframing, and writing a crisp one-pager.
  6. Weeks 9–10 · Capstone. A full requirements pack for a real partner scenario, presented to a review panel.

Placed as: Business Analyst, Product Analyst, Delivery Coordinator, Functional Consultant.

Eligibility: Any graduate. Two or more years of work experience in any industry strengthens your placement odds considerably.

Commitment: 12–15 hours a week.
