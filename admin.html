Existing candidates are not re-priced. Each one stores the rate they were signed up at, so changing the default here never alters what someone has already been billed. To move a specific candidate to a new rate, edit them and change their own Fee rate field.

The public website deliberately does not state the rate. It only says a placement fee applies after the first salary, so you can change the rate here without editing the site.
